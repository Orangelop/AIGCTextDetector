# AITextDetector

Online demo: https://orangelop.github.io/AIGCTextDetector/

The model used in this online demo was trained exclusively on Chinese writing text. Inputting other text will probably result in systematic bias in the output.

The files `train/train.py` and `train/loader.py` in this repository were written by me. The rest of the code was generated by Claude Opus 4.6 and tested by me.
